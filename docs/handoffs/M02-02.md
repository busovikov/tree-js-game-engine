## Decisions and invariants

- Component definitions are immutable package contributions; no process-global mutable
  component registry was introduced.
- `createEngineComponentRegistry()` is the runtime composition factory. `ProjectService`
  owns one assembled instance for editor load/save, and serializer APIs require injection.
- `cloneWorld()` copies component records by stable ID without consulting a central registry,
  so subsystem components survive undo/redo and snapshots without reversing dependencies.
- Scene camera discovery moved to the render owner because core must not know Camera.
- Persisted UUIDs are unchanged. No compatibility or migration layer was added.
- Schema modules still physically reside in `@haku/schema`; descriptor ownership is complete,
  schema ownership is explicitly not complete.
