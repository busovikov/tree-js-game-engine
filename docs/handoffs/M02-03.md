## Decisions and invariants

- Asset and asset-type identities are UUIDs; manifest paths are mutable locations, never
  identity.
- Component envelopes use UUID type IDs. Base definitions belong to `@haku/core`, physics
  definitions and schemas to `@haku/physics`, and render definitions and schemas to
  `@haku/engine`.
- `@haku/schema` retains only shared scene envelopes/primitives and project-wide settings.
  It does not re-export moved subsystem schemas.
- Registries are immutable package contributions assembled at composition roots. No
  process-global mutable registry or serializer fallback was introduced.
- Prefab files contain `{ "entities": [...] }`; scene documents do not embed a prefab map.
  `PrefabInstance.prefab` is a typed manifest UUID reference, and overrides are keyed by UUID
  component type.
- No compatibility branch accepts legacy paths, component names, `prefabId`, or embedded
  `SceneDocument.prefabs`.
- M03 must not start until the installed-Chrome smoke closes the final M02 gate.
