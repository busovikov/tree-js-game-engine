## Objective

Record the completed M07 visual graph-authoring slice. Haku owns strict graph assets,
commands, validation, persistence, compiler diagnostics, and runtime execution. React Flow
is a lazy replaceable editor adapter only. A shared diagnostic graph proves asset ->
compiler -> execution plan -> runtime -> world in editor Play, headless tests, and the
playground.

## Decisions and invariants

- `GraphAuthoringSession` owns graph state independently of React Flow. Saved assets pass
  `GraphAssetSchema`; selection, measured geometry, dragging, and other adapter state are
  never serialized.
- All add/move/property/connect/delete/duplicate/paste/replace operations execute through
  the existing Haku `CommandBus`. UI callbacks do not mutate graph JSON directly.
- Canvas connection checks provide immediate direction/kind/type/input-cardinality
  feedback, while `compileGraph()` remains the authoritative validator and diagnostic
  source.
- `GraphCanvasProvider` is replaceable. Its shared prop types live separately from the
  default lazy adapter so dependency analysis has no provider/adapter cycle.
- React and React DOM are deduplicated in the editor Vite composition root. This is required
  because a lazily optimized React Flow dependency otherwise receives a second React copy.
- Controlled canvas nodes seed only editor-local width, height, and handle geometry.
  React Flow can therefore render nodes and typed edges immediately; those values never
  enter Haku assets.
- Browser UUID generation calls `crypto.randomUUID()` through its receiver. A detached
  browser-native method throws `Illegal invocation`.
- Project graph create/load/save routes through `ProjectService`, validates strict JSON, and
  registers graph assets in the project manifest. Create/open and browser unload protect
  dirty graph state.
- The built-in diagnostic graph and registries live in `@haku/graph`. The runtime adapter is
  the explicit `@haku/graph-runtime/diagnostic-graph` subpath, avoiding a runtime index
  cycle.
- Editor Play and playground startup compile the same diagnostic asset and run the same plan
  adapter. M07 adds no editor-only runtime semantics or new loop.
- Dynamic physics makes the diagnostic checkpoint ineligible without making graph
  compilation fail. Inspector displays the causal rejection and all seven supported async
  policies.
- `@xyflow/react` is present only in the lazy editor canvas chunk. It is absent from the
  editor entry chunk and the playground production bundle.
