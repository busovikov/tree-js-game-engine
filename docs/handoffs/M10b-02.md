## Decisions and invariants

- A UI asset has one asset UUID, one root container UUID, and a flat strict element table.
  Container child UUIDs form the validated hierarchy.
- Runtime uses native semantic DOM and no React. The root is always a positioned containing
  block so anchored children work in arbitrary hosts.
- Text, visibility, and enabled mutations update existing nodes instead of replacing the
  tree, preserving native node identity and focus. Theme changes may rebuild the tree.
- Images contain typed asset references; only an injected resolver produces runtime URLs.
- `UIService` owns registered/mounted documents. SDK and graph adapters mutate only through
  its public surface and emit typed events/effect records.
- Visual authoring, selection, desktop preset choice, React hierarchy/Inspector, and
  command history remain editor-only. Only strict UI JSON is serialized.
- Built-in editor projects are read-only. Writable UI save uses the existing File System
  Access or dev-target storage boundary.
- M10b proves the production Vite composition boundary. Static self-contained ZIP export
  remains M10e.
