## Decisions and invariants

- `@haku/audio` remains DOM/Web-Audio-free. `@haku/audio-web` alone owns `AudioContext` and
  browser audio nodes.
- The preview button directly awaits `EditorAudioPreview.unlock()` before local byte loading and
  decoding. `unlock()` invokes `AudioContext.resume()` synchronously from the click call stack.
- `AudioContext.suspend()`/`resume()` promise rejection reaches the caller, and backend pause state
  changes only after the requested transition succeeds.
- Listener and panner pose use modern `AudioParam` properties, not deprecated `setPosition()` or
  `setOrientation()`.
- Audio imports are binary for WAV/MP3/OGG/M4A/AAC/FLAC; manifests store UUID/type/path metadata,
  while preview/runtime clips receive `Uint8Array` bytes.
- The playground generates a short WAV in memory. There is no remote audio URL and no new binary
  fixture to commit.
- Audio graph contracts declare only `audio` capability, static write resource, and external
  effect. Adapters use only the injected public service.
- No storage/platform/M10d code has been started.
