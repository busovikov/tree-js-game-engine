## Decisions and invariants

- `@haku/storage` is async and platform-neutral. The in-memory backend and IndexedDB backend
  implement the same optimistic revision contract.
- IndexedDB compare, revision increment, and `put` occur in one `readwrite` transaction.
  Code resolves writes only on transaction `complete`; aborts roll back the entire change.
- IndexedDB completion proves atomic browser persistence, not a synchronous physical disk
  flush. No unload-time save promise is made.
- Save slots and replay artifacts use separate in-memory maps and IndexedDB object stores.
- Browser storage `usage`/`quota` values are estimates and may be absent. The playground
  displays returned values without calling them exact.
- In-memory quota rejection calculates the replacement before mutation. Clone and quota
  failures leave the previous record unchanged.
- Replication is a discriminated union. Only explicit mode has transfer and conflict
  methods. `none` and `platform-managed` classes do not contain those properties at runtime.
- Optional numeric stats is an optional service object, not a method that throws when the
  capability is unavailable. Stats accept finite numbers only.
- `@haku/platform` owns no engine, input, audio, auth token, or SDK handle. It receives
  narrow callbacks and an optional auth provider.
- `visibilitychange` controls simulation/audio pause. Focus/blur controls input focus but
  does not falsely claim the page is hidden or pause simulation by itself.
- Platform pause reasons compose with browser visibility and are deterministic.
- `SaveSlotCheckpointService` implements the existing graph-runtime `SaveService`; the
  dependency points from storage to graph-runtime, never the reverse.
- Graph checkpoint migration/fallback remains in `GraphInstance`. The storage adapter
  preserves game data, sibling checkpoint entries, and corrupt checkpoint evidence.
- The playground platform adapter calls real `Engine.setPaused`, `InputManager`
  enable/disable, and `AudioDiagnostic.setPaused`. A lifecycle pause does not unlock Web
  Audio.
- No editor save-slot UI or save/platform graph nodes were added. The architecture assigns
  general cross-service nodes to M10f, and M10d has sufficient visible playground proof.
- No cloud/platform SDK is faked. The diagnostic uses local IndexedDB and browser lifecycle
  only.

## Official source grounding

- W3C Indexed Database API 3.0:
  `https://www.w3.org/TR/IndexedDB/` — transaction requests are ordered; abort rolls back
  all changes; commit atomically writes all changes or aborts; `complete` follows successful
  commit; quota failure is `QuotaExceededError`.
- MDN `IDBTransaction`:
  `https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction` — asynchronous
  transaction lifecycle and abort causes.
- MDN storage quotas and eviction:
  `https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria`
  — `navigator.storage.estimate()` returns estimates and over-quota IndexedDB writes fail
  with `QuotaExceededError`.
- MDN Page Visibility API:
  `https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API` —
  `visibilitychange` reports hidden/visible; focus/blur alone do not mean hidden.
- Yandex Games player data:
  `https://yandex.com/dev/games/doc/en/sdk/sdk-player` — authorization is platform-owned;
  player data and numeric stats have distinct APIs, sizes, and rate limits.
- Poki lifecycle:
  `https://sdk.poki.com/sdk-documentation` — platform lifecycle/gameplay events differ by
  provider, supporting a generic capability/lifecycle boundary rather than invented shared
  cloud methods.
