## Decisions and invariants

- IndexedDB transaction completion proves atomic browser persistence, not synchronous disk
  flush.
- Browser storage usage/quota numbers are estimates and may be absent.
- Real quota exhaustion was not forced because filling the user's origin/disk is unsafe and
  nondeterministic; typed quota behavior remains covered by deterministic tests.
- Save and replay namespaces remain separate. Rejected conflicts, clone failures, and quota
  failures preserve the current record.
- Only explicit replication exposes pull/push/flush/conflict behavior.
- Platform visibility and focus remain distinct. Visibility pauses simulation/audio and
  disables input; blur disables input without falsely claiming hidden or pausing simulation.
- `@haku/platform` owns no engine, input, audio, token, storage, or provider SDK handle.
- `@haku/storage` shared contracts live in `contracts.ts`; replication and graph checkpoint
  adapters import that leaf module so the public barrel has no dependency cycles.
- No editor save-slot UI, cloud/provider SDK, remote storage service, or M10e code was added.
