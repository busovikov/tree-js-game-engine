## Decisions and invariants

- Static export is browser-local and in-memory. No source, asset, or build output is sent to
  a Haku server.
- The browser client creates one lazy dedicated Worker. esbuild-wasm uses `worker: false`
  inside that Worker so it does not create a nested Worker.
- Root `index.html` must contain a local module entry. Export rewrites that entry to
  `./assets/runtime.js`.
- esbuild bundles and minifies project module imports. Literal
  `new URL(path, import.meta.url)` dependencies are validated, copied, and rewritten
  relative to the runtime output.
- Remote HTTP/protocol-relative URLs, project-root escapes, missing files, duplicate
  normalized paths, and unsafe ZIP paths fail closed.
- Manifest assets use `dependencyClosure()` from the entry scene. Unreachable manifest
  assets are not read or archived.
- Imported-untrusted projects fail before the export Worker is created.
- ZIP output is deterministic, UTF-8, ZIP32, store-only, ordered with root `index.html`
  first, and records Unix regular-file mode `0644`. Browser proof found and fixed the
  initially missing external file-mode attributes.
- Build diagnostics retain graph/type/code/UI source kind, path, line, column, and optional
  graph node, type, UI document, or UI element identity.
- Diagnostic navigation is replayable for late-mounted workspaces. Graph and UI select the
  precise authoring object; Code and Type open the source and Monaco reveals/focuses the
  location.
- The downloaded Blob URL is revoked on a deferred turn after the anchor click.
- No compression library, server build service, deployment integration, M10f node catalog,
  or compatibility layer was added.

## Risks and open limitations

- Static export recognizes the first local `<script type="module" src="…">` entry in root
  HTML. Multi-entry HTML is not an M10e contract.
- Runtime asset discovery supports literal `new URL(path, import.meta.url)` expressions.
  Dynamic asset paths cannot be closed statically and are not copied automatically.
- ZIP output intentionally uses the store method and ZIP32 limits. ZIP64 and compression
  are not implemented.
- Browser export was proved with a bounded engine-independent fixture. Cross-service graph
  integration and the combined UI/audio/save/pool/export playground scene belong to M10f.
