## Decisions and invariants

- `@haku/graph` contains metadata only. It never imports runtime adapters or executable
  callbacks.
- `@haku/graph-runtime` dispatches type/version-bound adapters and accepts narrow injected
  services. It does not own engine, storage, platform, UI, audio, or pool instances.
- Initial foundation IDs use the stable `74000000-...` namespace. Deterministic, world, and
  service categories use `74100000-...`, `74200000-...`, and `74300000-...`.
- Pure scalar/vector nodes have no hidden capability/effect. Variable state and seeded RNG
  are explicit bounded resources; both services support defensive checkpoint capture and
  restore.
- Physics is now an explicit node capability. Query, event, and body-write effects are
  distinct. Dynamic/unprovable physics dependencies are checkpoint-ineligible with causal
  chains; bounded transform/component/prefab nodes remain eligible.
- Save reads are conditional/materialized async operations; writes are unsafe async
  operations with wait/reject policy metadata. The next agent must prove these policies
  through compiler/runtime integration and must not weaken them to make a fixture compile.
- Save writes serialize through the public `ISaveStorage` expected-revision contract and
  preserve sibling keys. Platform capability results come only from
  `PlatformAdapter.queryCapabilities()`.
- Generated declarations are language-service inputs and remain non-editable.
- Existing pool, UI, and audio graph contracts/adapters are reused; do not duplicate them in
  the new catalog.
- No compatibility layer, M11 gameplay, provider SDK, server service, or new package is in
  scope.
