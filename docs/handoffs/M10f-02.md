## Decisions and invariants

- `@haku/graph` remains metadata-only. `createFoundationNodeRegistry()` owns graph
  registrations and accepts subsystem registrar callbacks rather than importing subsystem
  implementations.
- `@haku/graph-runtime` owns adapter composition, not services. Callers inject deterministic,
  world, save, platform, debug, pool, UI, and audio public services.
- The runtime adapter contract is in `runtime-adapter.ts`; executable adapter modules no
  longer import the public barrel and dependency-cruiser reports no new cycles.
- The deterministic snapshot provider accepts only `graph.variable` and `random.seeded`.
  Undeclared or dynamic resources fail rather than being serialized accidentally.
- Save Value retains `wait`/`reject`; Load Save Value retains `materialized`/`reject`.
- The combined playground diagnostic uses generated/in-memory data and an isolated Vite
  entry with `publicDir: false`; it does not depend on the live project manifest or HUD.
- The playground uses the narrow `@haku/build/browser-static-export` entry so its production
  closure does not acquire the browser Worker, TypeScript language Worker, or esbuild WASM.
- No compatibility layer, provider SDK, deployment, M11 code, push, PR, merge, or history
  rewrite is part of this stage.
