## Decisions and invariants

- Complex route generation remains typed Bounce Run TypeScript; lifecycle and bounded reuse remain
  the reusable public `@haku/pool` responsibility.
- `EntityPool.acquire(initializer)` is a general serializable placement seam. It runs after baseline
  restoration but before root activation and pool participants, so render and Rapier lifecycle
  participants observe final transform/component data. Initializer failure restores an inactive,
  reusable baseline and does not count an acquisition.
- The route owns leases from an otherwise inactive dedicated pool. `activeAhead` is at least two,
  `retainBehind` is non-negative, and their sum cannot exceed the pool maximum.
- At current platform `n`, the retained window is
  `[max(0, n - retainBehind), n + activeAhead)`, so the long-running maximum is exactly
  `activeAhead + retainBehind`.
- Pure route generation is rerun only to the requested horizon. Runtime stores only bounded active
  leases plus the intentionally append-only decision evidence; it does not retain an unbounded
  world entity or descriptor set.
- Box visual dimensions live in `MeshRenderer.geometryParams`; `Transform.scale` remains the
  authored prefab scale. Collider dimensions are the descriptor divided by two. This avoids a
  visual-only scale and avoids multiplying the prefab's non-unit geometry.
- `advanceForPosition` chooses the highest currently active platform center crossed by the ball.
  Fixed-step route updates therefore grow at most through already materialized reachability.
- The intentional `@haku/physics` dependency is public and direct: Bounce Run edits the public
  `ColliderComponent`, and does not rely on a transitive/private import.

## Risks and open defects

- The mandatory route is reachable with suitable lateral input; no-input browser smoke can still
  fall from a laterally offset platform. This is expected and is not an in-game QA bot.
- The route decision log intentionally grows with session distance. World entities, active leases,
  render objects, and physics bodies remain bounded.
- `advanceTo` releases obsolete leases before acquiring a disjoint window. A foreign lease can
  force a contained acquisition failure that leaves the route window empty; the dedicated runtime
  pool prevents that condition in Bounce Run.
- Rapier still emits its known initialization compatibility deprecation warning.
