## Objective

contract and stable canonical state hashes, then prove Bounce Run can replay a 180-tick public

divergence without mutating the recording.

## Decisions and invariants

- Canonical hashing and fixed-tick artifact mechanics are general public `@haku/core` primitives;
  Bounce Run owns its typed action validation, initial replay state, tuning, and controller reducer.
- Canonical data is JSON-shaped plain data. Object keys use default ECMAScript UTF-16 sort, strings
  use JSON escaping, numbers never use locale formatting, and the canonical string is UTF-8 hashed
  with lowercase FNV-1a 64 (`fnv1a64:<16 hex>`).
- FNV-1a is a deterministic divergence fingerprint, not a cryptographic integrity primitive.
- Record calls are transactional: tick, action, and state validation complete before the immutable
  frame is appended. Frames are contiguous from tick zero and cannot exceed the declared count.
- Replay validates and clones the complete deterministic artifact before stepping, clones the
  initial state, passes frozen action snapshots to the reducer, and never mutates caller input.
- Bounce Run replay deliberately hashes the controller-visible velocity state and does not claim to
  serialize or restore Rapier internals, consistent with the checkpoint architecture.
- No graph node was added: recording/hashing is a service/algorithm boundary and the current slice
  proved no orchestration deficiency requiring a node.
