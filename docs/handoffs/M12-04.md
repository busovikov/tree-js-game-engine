# Handoff: M12 public structured observations and declarative assertions

## Objective

Complete the fourth bounded M12 semantic slice: provide reusable immutable structured
observations and safe declarative field-path assertions, then prove Bounce Run can compose one
versioned fixed-tick snapshot exclusively from public scheduler/session/ball/route/pool read
surfaces without exposing a mutation capability.

## Scope and acceptance criteria

- [x] The required first RED imported missing `createBounceRunObservationSnapshot` and
      `evaluateBounceRunAssertions` and failed with module-not-found before implementation.
- [x] Generic snapshots clone and deeply freeze finite plain JSON-shaped state.
- [x] Accessors, callbacks, symbols, BigInt, cycles, sparse/non-plain arrays, non-plain objects, and
      non-finite values are rejected without invoking user code.
- [x] Stable guarded dot/array paths support `eq`, `ne`, `lt`, `lte`, `gt`, and `gte` and return
      immutable structured results with code, path, operator, expected, actual, and pass/fail.
- [x] Unknown/escaping paths, prototype-pollution segments, unknown operators, duplicate codes,
      invalid numeric operands, extra mutation fields, and malformed observations are rejected
      transactionally.
- [x] The Bounce Run adapter emits only version/tick/session/ball/bounded route/pool data from
      public read methods; source and snapshot cannot mutate one another.
- [ ] Immutable session/bug report composition and export remain the next M12 slice.
- [ ] Browser automation and production QA exclusion remain later M12 slices.

## Decisions and invariants

- Immutable JSON cloning remains one shared `@haku/core` primitive used by recording,
  observations, assertion inputs, and results; unsupported data is rejected before JSON parsing.
- Path evaluation only traverses own fields on the cloned observation. `__proto__`, `prototype`,
  and `constructor` segments, malformed indexes, and unknown fields are never traversed.
- Equality compares the existing canonical JSON representation. Ordering comparisons require
  finite numeric actual and expected values; boolean existence was not added because no use case
  justified broadening the operator contract.
- Existing graph `Assert` remains the public boolean flow-node contract. No duplicate graph node
  or callback-bearing assertion surface was introduced.
- The Bounce Run adapter selects bounded plain data and returns no `IWorld`, entity/pool handle,
  service, setter, callback, or mutation method. It is headless and is intentionally not wired into
  `main.ts` yet.
- No browser/report, editor, React, audio, storage, M13, or M14 code was opened or changed.
