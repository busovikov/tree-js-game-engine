## Decisions and invariants

- Numeric score and furthest-awarded route index live only in the graph variable store. The landing
  boundary injects the current mandatory lease index as a typed graph event value; Greater Than,
  Branch, Add, Get, and Set nodes own the forward-only rule and restart reset.
- LandingTracker remains authoritative for top contact, downward velocity, and once-per-tick landing.
  Entity identity is not progression identity: the graph compares the bound platform index, so a
  reused pool entity cannot award an older index again.
- Explicit `Format Number` is a pure reusable graph conversion. Public UI Set Text nodes alone mutate
  score presentation. Successful declared graph writes advance resource revisions for later execution
  snapshots; the current execution retains its frozen inputs.
- `bounce-run.high-score.v1` contains `{ schemaVersion: 1, highScore: safe non-negative integer }`.
  Missing/malformed data reads as zero. Writes include expected revision, happen only for a strictly
  higher candidate, and retry a conflict at most once after a safe re-read.
- Quota, conflict, and operation rejection leave the prior slot and loaded HUD value intact while the
  fail transition still reaches game-over; the returned promise surfaces the public typed error.
- Production probes IndexedDB through the public backend. Only `SaveStorageUnavailableError` selects
  in-memory storage, and the start UI discloses that the best score then lasts only for the tab.
