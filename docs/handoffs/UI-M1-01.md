## Decisions and invariants

- Version 1 has no reader, adapter, alias, fallback, or dual writer.
- Serialized containers are `frame`, `scroll-container`, and `list`; `container` exists only in the
  deliberate version 1 rejection test.
- `UIRuntimeEvent.bindingId` replaces the old activation-only `eventId` surface.
- `UIRuntimeTarget` accepts either a top-level element ID or an instance locator.
- Component descendants expose the top-level selectable ID plus source ID and instance path.
- Programmatic value writes never dispatch user events; user state is committed before dispatch.
- M0 `it.fails` ownership remains M3/M5; the compiler shape changed but those UX defects were not
  fixed.
- Protected playground project/UI asset paths remain excluded from every read, edit, stage, and
  commit operation.
