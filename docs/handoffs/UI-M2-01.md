## Decisions and invariants

- `activeWorkspace` is editor-store routing state. Only UI bypasses the scene body; Graph and Code
  retain their previous center-panel behavior.
- Scene splitters keep their original autosave IDs. UI has its own `haku-ui-editor-panels-h` state,
  so switching surfaces does not reuse or destroy scene panel proportions.
- Zoom is clamped to 10%–800%. Fit and manual zoom are view state, not `UIDocument` fields.
- Preset/custom viewport and Edit/Preview mode live in `UIAuthoringSession` only. Save serializes
  the strict asset and excludes those fields.
- The preview is always CSS-centered so a browser resize retains its root-center focal point even
  when a test viewport override omits observer notifications. Fit directly remeasures the current
  host; `ResizeObserver`, window resize, and visual-viewport resize remain active with cleanup for
  production panel/window changes.
- The existing Asset Browser is mounted only inside an explicit closeable asset dialog. There is
  no permanent Asset Browser in UI mode.
- Direct canvas interaction belongs to M3 and is intentionally absent.
