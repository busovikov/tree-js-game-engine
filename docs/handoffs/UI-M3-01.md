## Decisions and invariants

- Selection, editor lock state, gesture drafts, guides, preview mode, viewport, and canvas
  transform are editor-only and absent from serialized UI JSON.
- The last selected ID is primary. Shift toggles only siblings with a common parent; an invalid
  cross-space toggle becomes a single selection.
- Selection-only changes do not remount runtime nodes, preserving native state and focus.
- Only free and absolute placement can begin move/resize. Auto-layout reorder and all structural
  hierarchy editing remain M4.
- Gesture previews alter runtime inline styles and overlays only. Pointerup performs one strict
  `replaceAsset`; cancel restores the exact captured style without a command.
- Snap priority is parent edge, peer edge, center, parent padding, then equal gap. Ctrl/Meta bypass
  applies only during an active editing gesture.
- Ordinary wheel/trackpad input is zoom in Edit. Middle-drag and Space+drag are the dedicated pan
  gestures. Wheel is consumed only in Edit; Preview returns before `preventDefault()`.
- Resize handles convert only their edited axes to Fixed px. The M5 Inspector field model and its
  two `it.fails` cases are intentionally unchanged.
