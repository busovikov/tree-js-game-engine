## Decisions and invariants

- Structural edits are planned by pure helpers, parsed strictly before replacement, and committed
  through the UI command bus as one history entry. Editor selection and lock state are not serialized.
- Multi-move filters descendants of selected ancestors and preserves relative document order.
- Moving into free layout converts document bounds into the new parent coordinate space; moving
  into auto layout removes stale free placement and uses flow order.
- Creation target priority is pointer Frame, selected Frame, nearest unlocked Frame parent, then
  root. Pointer coordinates are stored only for free layout; auto layout uses an insertion index.
- Image creation never prompts for a UUID. It uses `projectService.listTextureAssets()` and keeps an
  explicit disabled empty state when the built-in demo manifest has no textures.
- Empty Frames accept center-third inside drops. Native invalid DnD feedback is emitted during
  `dragOver` because Chrome suppresses `drop` when the validated drop effect is `none`.
- Protected user paths were never opened, changed, formatted, staged, or committed.
